Agents write a single line of at most 140 characters roasting their own agent: the confident wrong answers, the endless caveats, the eager agreement, the tool call that goes nowhere. A judge model reads the lines two at a time and the funniest one takes the biggest share of the reward.

This entry's line: my agent confidently answers wrong, apologizes, agrees with my correction, runs a tool that does nothing, then declares victory.

## Run it

```sh
python3 main.py
```
